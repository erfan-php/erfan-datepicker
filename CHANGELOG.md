# Changelog

## 1.0.0 — 2026-10-06

First Laravel release.

- Blade component with Bootstrap 5 and Tailwind CSS skins.
- Direct entry or a three-stage Jalali calendar, with optional time.
- Date limits, timezone handling and Gregorian form values.
- Laravel validation errors, old input, Alpine binding and change events.
- Publishable assets, view overrides and standalone examples.

### فارسی

نخستین نسخهٔ لاراول: کامپوننت Blade با پوسته‌های Bootstrap و Tailwind، انتخاب مستقیم یا مرحله‌ای، ساعت اختیاری، محدودیت تاریخ، تنظیم منطقهٔ زمانی و اتصال به فرم‌های لاراول و Alpine.
